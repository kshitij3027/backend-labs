# log-query-api-rest — Python dependencies (pinned FastAPI stack).
#
# Pins are EXACT so image builds are reproducible and offline-friendly. This layer is
# installed before the app source is copied, so it caches once and code changes only
# rebuild the thin source layer on top of it. Everything here resolves to a prebuilt
# manylinux wheel on python:3.11-slim — no C toolchain required.
#
# Deliberately NOT here: any database driver, Redis client, or ORM. The log store is
# an in-process, in-memory append-only structure with secondary indexes, and the rate
# limiter's token buckets live in the same process. Introducing a backing store is a
# separate decision, not an accident of this file.
